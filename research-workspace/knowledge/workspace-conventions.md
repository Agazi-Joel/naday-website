# Workspace conventions

This file is the shared rulebook. Every skill reads it so they behave consistently.
If you change a rule here, the whole workspace follows.

## The paper pipeline

PDFs move through three folders, left to right:

| Folder | Meaning | What happens here |
|---|---|---|
| `papers/1-to-read/` | Downloaded, not yet engaged with | New PDFs land here (from Zotero, a journal site, anywhere). |
| `papers/2-processing/` | Being read & annotated | Highlight + comment in your PDF reader, then save the annotated copy here. Skills extract notes from these. |
| `papers/3-to-cite/` | Confirmed for the essay | Only papers you've decided to actually cite. The reference list is built from this folder. |

Move a paper forward only when you've genuinely finished that stage. The folder a
paper sits in is the single source of truth for "where am I with it."

## Where things are written

- **Notes** → `notes/`, organised **by theme/argument**, not by paper (one paper often feeds several themes).
- **Outputs** (drafts, slides, summaries) → `outputs/`.
- **The live assignment** (title, brief, word count, deadline, marking criteria) → `knowledge/current-question.md`. Skills read this to stay on-topic. Keep it updated.

## File naming

- Papers: `AuthorYear-shorttitle.pdf` (e.g. `West2017-collective-leadership.pdf`).
- Notes: `theme-name.md` (e.g. `system-leadership.md`).
- Outputs: `assignment-shortname-vN.md`.

## Citation style

Default is **Harvard (Cite Them Right)** — see `knowledge/citation-style.md`.
Confirm against the module handbook; if it differs, change that one file and every
skill follows.

## Academic integrity (read this)

This workspace is a **thinking and structuring partner, not a ghostwriter.**

- Reflective and analytical prose must be **her own words and judgement**.
- Skills may: find sources, summarise papers, organise notes, critique arguments,
  ask questions, propose structures, and check that claims are cited.
- Skills must **not** fabricate references, invent quotes, or hand over finished
  prose to be submitted as-is. Drafting skills produce **clearly-labelled working
  drafts** to be rewritten in her voice.
- Every factual or theoretical claim traces back to a real, verifiable source.
  If a source can't be verified, flag it rather than cite it.
