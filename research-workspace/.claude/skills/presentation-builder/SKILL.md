# Presentation builder

Reshape her material into a talk. Presentations need a different spine from an essay:
fewer points, sharper narrative, one idea per slide.

## Inputs
- An outline, draft, or `notes/`, plus the brief (audience, time limit, purpose).
  Ask for these if not given.

## Steps
1. Establish: audience (academic? trust board? mixed?), time, and the single
   message she wants to land.
2. Build a slide-by-slide outline.

## Output
For each slide:
- **Slide title**
- **3–5 bullet points** (concise — talking points, not paragraphs)
- **Speaker notes** — what she says, in prompts not a script (her delivery, her voice)
- **Visual suggestion** where useful (model diagram, data, framework)

Suggested arc: Title → Why this matters (hook) → Question/aim → Key argument(s) with
evidence → Application to practice → Implications/recommendations → Conclusion →
References. Adapt to the time limit (~1–2 min per content slide).

Save to `outputs/<assignment>-slides.md`.

## Rules
- Cite sources on evidence slides + a closing references slide (Harvard).
- Speaker notes are prompts she'll deliver in her own words, not a script to read.
- For a board/practice audience, lead with the practical "so what."
